# pyrlyn/cla

A GitHub Action that checks the pyrlyn Contributor License Agreement on pull requests. It is
meant to replace CLA Assistant Lite (`contributor-assistant/github-action`, archived) in the
reusable `cla` workflow of [`pyrlyn/infra`](https://github.com/pyrlyn/infra).

Status: **planning**. There is no code yet.

- [`PLAN.md`](PLAN.md): the plan (English, source of truth).
- [`docs/ru/PLAN.md`](docs/ru/PLAN.md): Russian translation.
- [`docs/uk/PLAN.md`](docs/uk/PLAN.md): Ukrainian translation.

The agreement itself lives in `pyrlyn/infra`: [`CLA.md`](https://github.com/pyrlyn/infra/blob/main/CLA.md)
(canonical) and [`CLA.ru.md`](https://github.com/pyrlyn/infra/blob/main/CLA.ru.md).
